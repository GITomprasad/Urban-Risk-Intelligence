# 🏙️ Urban Risk Intelligence

> An interactive data-driven platform for analyzing, visualizing, and communicating city-level risks through centralized urban intelligence.

## 🚀 Overview

**Urban Risk Intelligence** is a modern web platform designed to bring urban-risk information, analytics, alerts, and predictive insights into a single interactive interface.

The project focuses on helping users explore city-level risk conditions, understand patterns, monitor alerts, and support data-driven decision making through clear visualizations and intelligent analysis.

## ✨ Key Features

- 📊 **Analytics Dashboard** — Explore urban risk metrics, trends, and key indicators.
- 🏙️ **City Intelligence** — Analyze risk information across different cities.
- 🤖 **AI Engine Inspector** — Inspect the intelligence and analysis layer behind the platform.
- ⚠️ **Alert Management** — View and manage urban risk alerts.
- 🔎 **Cell Detail Analysis** — Inspect detailed risk information at individual data cells.
- 📈 **Predictive Timeline** — Explore risk trends and future-oriented insights.
- 🩺 **Data Health Monitor** — Monitor data quality and system health.
- 🎛️ **Live Command Center** — Centralized interface for monitoring urban conditions.
- 👥 **Citizen Portal** — Present important urban-risk information through a user-friendly interface.
- 📱 **Responsive UI** — Designed for modern web and desktop experiences.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/GITomprasad/Urban-Risk-Intelligence.git
```

### 2. Navigate into the project

```bash
cd Urban-Risk-Intelligence
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
